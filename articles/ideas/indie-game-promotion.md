# Indie Game Promotion Strategy

Notes from a data breakfast (DDS) in Berlin about how to promote indie games[^1].

## The plan

Make a game and start promoting it on your own accounts. Run accounts on YouTube, Instagram, and TikTok in parallel - either dedicated to the game or personal accounts. Post actively and consistently. Consistency is the main thing - do not skip[^1].

## Demo platforms

There is a special platform for games where you can publish demo versions for people to play. It generates some traffic on its own. On the platform page, point to the full version on Steam. The exact name of the platform was not remembered, but it can be found through ChatGPT[^1].

## Steam wishlisting

On Steam, do not publish the full version right away. Create a wishlist (waiting list) first. If people like the demo, they sign up for the waitlist. Once the waitlist has enough interest, sell the full version through it[^1].
