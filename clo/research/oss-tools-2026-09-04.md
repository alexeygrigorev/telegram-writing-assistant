# New open-source AI engineering tools (past 2-3 weeks)

## Agent harnesses / runtimes
- **TrueForge** (TrueFoundry) — MIT, npx quickstart. Full harness: execution loop, MCP tools, skills/SKILL.md, sandboxing, approvals, context compaction, session state; SQLite local / Postgres+Redis hosted. Claims 30-75% cheaper than Claude Managed Agents at comparable solve rates. Open-sourced mid-Aug, ~5.2k stars.
  https://github.com/truefoundry/trueforge ; blog: https://www.truefoundry.com/blog/engineering/trueforge-open-source-agent-harness/ ; X article: https://x.com/truefoundry/article/2090081376330715176 ; Reddit roundup: https://www.reddit.com/r/AIGuild/comments/1w0sfm5/
- **OneCLI** — Apache 2.0, ~3.4k stars. Sandboxed team harness: per-agent sandboxes, credential injection at gateway (never in agent context), centralized policy, approvals, works with Claude Code via proxy. YC S26 Launch HN (~2wk ago, 88+ pts): https://news.ycombinator.com/item?id=49363710 ; https://github.com/onecli/onecli
- **Proliferate** — self-hostable Codex for any coding agent. Show HN 46 pts: https://github.com/proliferate-ai/proliferate

## MCP tooling
- **GitHits (githits-cli)** — Apache 2.0, ~88 stars. MCP server + CLI: indexed public OSS code, package docs, symbols, changelogs, vulns at specific Git refs. Kills dependency-blindness of coding agents. Reddit launch Aug 31: https://reddit.com/r/MCPservers/comments/1w35vna/ ; https://github.com/githits-com/githits-cli
- **extensible-mcp** (SenteLabsAI — same org as OpenExecutive!) — Apache 2.0. MCP proxy: on-demand server loading (less context bloat), searchable tool retrieval, Rego policy filters, enforcement outside the model. Show HN ~Sep 2: https://news.ycombinator.com/item?id=49520552 ; https://github.com/SenteLabsAI/extensible-mcp
- **Aura FHE MCP** — encrypted MCP server for private agent context. X Sep 4: https://x.com/AfheLabs/status/2095794495014986224 ; https://github.com/aurafhe-official/mcp

## Context / memory / observability
- **ambient-context** — screen memory as text→Markdown, no screenshots. Show HN 62 pts: https://github.com/dragthelake/ambient-context
- **OzBrain** — shared knowledge brain between agents and team. Show HN 93 pts, 59c: https://ozbrain.com
- **Tokensift** — token-efficiency linter for prompts. Show HN ~Aug 29: https://news.ycombinator.com/item?id=49487500
- **opslane** — watches user sessions, finds bugs that matter, fixes them. Show HN 40 pts: https://github.com/opslane/opslane

## Inference / routing / training
- **NVIDIA PAIR (Personal AI Router)** — Apache 2.0. LAN inference router: mDNS discovery of Ollama/LM Studio/OpenAI-compat nodes, mTLS, routes by workload; no VRAM pooling. NVIDIA blog Sep 3; @RaajKapadia X thread Sep 4: https://x.com/RaajKapadia/status/2095786097934754288 ; https://github.com/NVIDIA/Personal-AI-Router
- **experiential** (ExperientialLabs) — "open OpenRouter that turns usage into a better model" (data flywheel from routed usage). Show HN 220 pts: https://github.com/experientiallabs/experiential
- **MILES** — RL/post-training framework (mid-Aug roundup, less traction data)

## Fun / edge
- **CarWatch** — Raspberry Pi + Qwen local car assistant. Show HN 146 pts: https://github.com/ThinkOffApp/CarWatch

## Pattern of the wave
Security/policy/governance for agents dominates (OneCLI, extensible-mcp, Aura FHE, Proliferate), plus cost (TrueForge, Tokensift) and MCP context hygiene. Matches the durability/ops themes from the Sep articles.
