## Tools

Week of August 31 – September 4. The wave of the week: governance for agents. Sandboxing, policy enforcement, and credential control dominate the new releases, with cost tooling right behind.

* **[experiential](https://github.com/experientiallabs/experiential)**: an open-source OpenRouter alternative that turns routed usage into a better model. Every request that flows through the gateway becomes training signal, so the router keeps improving from real traffic instead of static leaderboard scores. It's useful when you want provider routing without sending your data to a closed intermediary. Topped this week's Show HN at 220 points.
* **[TrueForge](https://github.com/truefoundry/trueforge)**: an open-source agent harness that runs the full loop, model calls, MCP tools, skills, sandboxing, approvals, context compaction, and session state, in any model provider. TrueFoundry's benchmarks put it 30-75% cheaper than Claude Managed Agents at comparable solve rates, with a local SQLite mode and a hosted Postgres/Redis mode. It's useful as a self-hosted starting point for production agents. MIT, npx quickstart, around 5.2k stars.
* **[OneCLI](https://github.com/onecli/onecli)**: a sandboxed agent platform for teams that gives every employee or agent an isolated environment and injects credentials at the gateway, so secrets never enter the agent's context or memory. Centralized policy, approvals, and integrations for GitHub and Gmail, and it fronts existing agents like Claude Code through a proxy. It's useful when multiple people run agents against shared company systems. Apache 2.0, about 3.4k stars, YC S26.
* **[extensible-mcp](https://github.com/SenteLabsAI/extensible-mcp)**: an MCP proxy from the OpenExecutive authors that sits between agents and MCP servers, loading servers on demand so tool definitions stop bloating context, and enforcing Rego policies outside the model where they can't be talked around. It's useful for keeping a growing MCP sprawl both discoverable and governed. Show HN this week.
* **[GitHits](https://github.com/githits-com/githits-cli)**: an MCP server and CLI that gives agents indexed access to public open-source code, package docs, symbols, changelogs, and vulnerability data at specific git refs. Instead of guessing how a dependency behaves or falling back to web search, the agent queries the exact version it runs. It's useful for coding agents that keep tripping over dependencies they can't see.
* **[Personal AI Router](https://github.com/NVIDIA/Personal-AI-Router)**: a local inference router from NVIDIA that discovers Ollama, LM Studio, and OpenAI-compatible endpoints across a LAN via mDNS and routes requests to whichever node has the right model free, with mTLS and no VRAM pooling. It's useful for spreading parallel workloads, one node on vision, another on embeddings, across machines you already own. Apache 2.0.
* **[ambient-context](https://github.com/dragthelake/ambient-context)**: a screen memory tool that captures what's on your screen as plain text Markdown instead of screenshots. Agents get readable history of what you were looking at, at a fraction of the token cost of images. It's useful for context engineering setups that want ambient awareness without vision-model overhead.
* **[Tokensift](https://news.ycombinator.com/item?id=49487500)**: a linter for prompt token efficiency that flags redundant instructions, dead context, and bloated system prompts before they ship to production. It's useful as a CI check for teams whose agent prompts quietly grew three sizes this year.
* **[Proliferate](https://github.com/proliferate-ai/proliferate)**: a self-hostable, open-source version of Codex-style cloud execution for any coding agent, giving CLI agents a managed environment for long-running tasks. It's useful when you want agent compute on your own infra. Show HN this week.
* **[OzBrain](https://ozbrain.com)**: a shared knowledge brain that sits between agents and your team, keeping one canonical store of decisions and docs that both humans and agents read from. It's useful for the "agents and people keep forgetting the same things" problem. Show HN at 93 points.
