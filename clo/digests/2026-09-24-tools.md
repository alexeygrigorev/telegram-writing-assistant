## Tools

Week of September 17 – September 23. The wave of the week: running coding agents in parallel without breaking things. Sandboxes for isolation, a coordination protocol for intent conflicts, and code-intelligence layers that feed agents exact context instead of grep dumps, plus local-first harnesses and cheaper evals.

* **[brig](https://github.com/brig-sh/brig)**: a sandbox runner that executes coding agents inside lightweight microVMs with their own Linux kernel on Mac and Linux. Its standout detail is hardware-level isolation at low overhead: its own microVMM under 20k lines of code, selective sharing of projects and credentials via writable mounts with optional internet, ephemeral or session-based runs, profiles for popular agents or bring-your-own OCI images, installed via Homebrew with a `brig run claude ~/project` CLI. It's useful when you want auto-approving agents without handing them your keys and home directory. Apache 2.0, Go, around 130 stars, Show HN this week.
* **[foremerge](https://github.com/naw103/foremerge)**: a coordination protocol for parallel coding agents that catches intent conflicts before code conflicts, built above Git. Its standout detail is the pre-merge check: agents declare what they intend to change and the protocol flags overlapping intent while the work is still cheap to redirect, instead of discovering the collision in a merge conflict after the tokens are spent. It's useful when you run several agents on the same repo at once. Rust, around 503 stars, Show HN this week at 45 points.
* **[Benzi](https://github.com/oooscoos/Benzi)**: an AI-native code intelligence layer that compiles codebases into a queryable map of calls, data flow, and references with O(1) lookups. Its standout detail is per-language tree-sitter grammars for Python, JS/TS, Java, C#, C++, C, Go, Rust, and Ruby feeding one query map, plus static analysis, runtime tracing, and MCP server exposure, reporting 78.2% on SWE-bench Verified at under 10 cents per fix while reading far less code than competitors. It's useful when RAG-over-code keeps stuffing context with near-misses. Around 85 stars, Show HN this week.
* **[forcefield](https://github.com/fabledruns/forcefield)**: an ultra-fast local-first agent harness in Go shipped as a single binary. Its standout detail is minimalism for local models: sessions with memory, skills, permissions, and shell execution, model abstraction across Ollama, LM Studio, llama.cpp, and remote providers, no accounts or telemetry, with TUI support and fast startup. It's useful when config-heavy tools fight your local-model setup and you want a small binary that just runs agents. Apache 2.0, Go, early traction at 6 stars, Show HN this week.
* **[apowerb](https://github.com/apowerb/apowerb)**: an open-source agentic platform for building and operating production agents with a FastAPI backend. Its standout detail is dynamic agent materialization: agents are defined in the database rather than static code and execute via Google ADK, model-agnostic through LiteLLM, self-hosted via Docker Compose with an admin panel, a catalog of over 100 tools across Google and Microsoft 365, SQL, RAG, and web, plus skills and MCP support. It's useful when you outgrow one-off agent scripts and need an operable runtime with a tool catalog. Apache 2.0, Python, around 33 stars, Show HN this week.
* **[lossless-memory](https://github.com/aru-labs/lossless-memory)**: a personal long-term memory layer for AI assistants that never summarizes and keeps every line with a timestamp. Its standout detail is the no-compaction bet: instead of rolling up history into lossy summaries, it stores verbatim lines and retrieves by recency and relevance, trading storage for fidelity in personal-assistant setups where the summary always seems to drop the one detail that mattered. It's useful for always-on assistants where "what did I tell you last Tuesday" must return the exact words. Python, around 109 stars, Show HN this week at 67 points.
* **[jevals](https://github.com/openlayer-ai/jevals)**: an eval and guardrail library that replaces LLM judges with typed Jev decisions. Its standout detail is cost and speed for the agent loop: one request per trace at a fraction of a cent, fast enough to run inline rather than as an offline batch, running locally with Kev or Laya runtimes. It's useful when LLM-as-judge bills and latency keep evals out of the hot path. Python, around 80 stars, Show HN this week at 47 points.
