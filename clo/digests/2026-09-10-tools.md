## Tools

Week of September 3 – September 9. The wave of the week: local-first memory for agents. Two new memory engines launched within days of each other, both SQLite-or-single-binary, both MCP-native, both promising to end agent amnesia without cloud infra, with agent-visibility tooling right behind.

* **[engrim](https://github.com/timgordontg/engrim)**: a local-first SQLite memory engine that keeps one project-scoped episodic store across Antigravity, Claude Code, Cursor, Windsurf, and Codex, so switching models mid-project loses nothing. Its standout detail is the 105-session case study on a 50,000-line trading codebase: 153,000 tokens of decisions consolidated into a sub-1,000-token memory pack, a 99%+ cut in reloaded context on every restart, with hybrid BM25 plus static model2vec embeddings and zero-latency reciprocal-rank fusion. It's useful when you clear agent sessions freely but want architectural decisions to survive. MIT, around 220 stars, Show HN this week at 92 points.
* **[fraise](https://github.com/FraiseHQ/fraise)**: an in-memory knowledge store for agents that speaks a two-verb query language built for tokens, not humans: `remember` and `recall` over a temporal bipartite graph with hybrid graph, text, and vector retrieval. Its standout feature is the single-binary, no-infrastructure deployment with an MCP server for cross-session persistence (`claude mcp add fraise`), scoring 0.893 recall at k=10 on the LoCoMo benchmark against heavier setups like mem0, Letta, and Graphiti. It's useful for giving agents cheap persistent memory without running a vector database. MIT, Go, Show HN this week.
* **[geiger](https://github.com/Atomburstofficial/geiger)**: a read-only inventory command that lists every AI agent, harness, MCP server, plugin, and AI extension on a machine and says in plain language what each one can touch. Its standout detail is the exposure labeling: every finding gets tags like EXECUTES, BROAD-FILESYSTEM, or HOLDS-SECRETS, plus redacted credential detection in config files, all from `npx geiger-scan` with zero dependencies and no telemetry. It's useful for answering "what is actually running on this machine" after months of one-click agent installs. MIT, around 88 stars, Show HN this week at 44 points.
* **[MaskShift](https://github.com/nafeeur/MaskShift)**: a maximalist, model-agnostic coding harness for the terminal that puts 149 native tools and 44 bundled skills behind one control plane, inserting only the relevant capabilities into model context per step. Its standout feature is the zero-runtime-dependency build on Node 22 built-ins only, covering filesystem, Git worktrees and checkpoints, LSP, browser over CDP, containers, SSH, databases, parallel agents, scheduled automations, and lazy MCP loading, with a text protocol that gives full tool use even to models without native tool-calling. It's useful when you want the whole workshop in one terminal harness without an npm dependency tree. GPL-3.0, Show HN this week.
* **[booley](https://github.com/boldaxolotl/booley)**: an open-source agentic IDE for RTL and chip design that wraps simulation, linting, synthesis, and FPGA flows in one reproducible VS Code plus Docker workspace. Its standout feature is waveform-aware debugging: the `bwave` CLI lets the agent query real simulation traces ("how many handshakes between 1,000 and 2,000 ns?") instead of guessing from code, with strict ticket-mode acceptance criteria for area, cycle counts, coverage, and mutation testing. It's useful for hardware teams that want agents to touch EDA tooling without touching host git history. Apache 2.0, Show HN this week.
* **[oto-dock](https://github.com/OtoDock/oto-dock)**: a self-hosted company OS where agents organized in departments connect to company tools, delegate to each other, and keep working unattended, running on your own Claude or Codex subscription instead of per-seat agent pricing. Its standout detail is multi-tenancy by design with four sharing modes, a self-hosted dashboard plus phone-line access, and support for Claude Code, Codex, API keys, and local models at version 1.6.0. It's useful for small teams that want shared agents on infrastructure they control. Fair-source license (FSL-1.1-Apache-2.0), around 109 stars, Show HN this week at 44 points.
* **[AutoRAG](https://github.com/Marker-Inc-Korea/AutoRAG)**: an agent-driven RAG pipeline that searches, reads, and curates answers from files on your own computer, with feedback-based memory that adapts retrieval from user corrections. Its standout detail is the v2.4.1 release from early September, keeping a steady update cadence on a codebase the community already trusts. It's useful when your knowledge lives in local files and you want retrieval that learns from what you accept or fix. Around 5.1k stars.
