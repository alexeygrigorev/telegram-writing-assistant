## R40 — Agent Factory: Top 5 agent observability best practices for reliable AI

- **Phase:** Run
- **Priority:** Strong
- **Format:** Operational guide
- **Publisher / speaker:** Microsoft Azure
- **Published / updated:** 2025-08-27
- **Evidence type:** Primary official operational guidance

**Why it is relevant.** Extends traditional metrics, logs, and traces with continuous evaluation and governance so teams can inspect agent decisions, tool use, safety, compliance, and production drift.

**Best classroom use.** Use to turn the runbook into a concrete observability checklist spanning monitoring, tracing, logging, evaluation, governance, alerts, and release gates.

**Source:** [https://azure.microsoft.com/en-us/blog/agent-factory-top-5-agent-observability-best-practices-for-reliable-ai/](https://azure.microsoft.com/en-us/blog/agent-factory-top-5-agent-observability-best-practices-for-reliable-ai/)

- **Format:** Security guide

## R43 — Secure agentic systems

- **Phase:** Run
- **Priority:** Strong
- **Format:** Security guide
- **Publisher / speaker:** Microsoft Secure Future Initiative
- **Published / updated:** 2026
- **Evidence type:** Primary official security guidance
