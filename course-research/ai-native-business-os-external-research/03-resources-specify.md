## R14 — Effective context engineering for AI agents

## R17 — Understanding Spec-Driven Development

## R21 — How to write a great agents.md: Lessons from over 2,500 repositories

- **Phase:** Specify / Run
- **Priority:** Core
- **Format:** Research-backed guide
- **Publisher / speaker:** GitHub
- **Published / updated:** 2025-11-19
- **Evidence type:** Primary practitioner analysis

**Why it is relevant.** Finds that effective specialist agents need a precise job, executable commands, concrete examples, project context, and explicit boundaries—not a generic helper prompt.

**Best classroom use.** After the workflow-specification exercise, have learners compress their SOP into an agent operating file with commands, examples, and clear 'do not' rules.

**Source:** [https://github.blog/ai-and-ml/github-copilot/how-to-write-a-great-agents-md-lessons-from-over-2500-repositories/](https://github.blog/ai-and-ml/github-copilot/how-to-write-a-great-agents-md-lessons-from-over-2500-repositories/)
